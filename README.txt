This is an achievable first working two-scene 3D/AR prototype. Models are original procedural interpretations informed by real scenic landmarks; NOT photorealistic reconstructions, scans, geographic surveys, or real-location photographs. Both sites have a lake/forest or waterfall/rock/forest visual identity. To reach photorealism later, source appropriately licensed photos, terrain/photogrammetry, and professional PBR assets and rebuild models in Blender.

IPHONE TEST
1. Extract the ZIP.
2. In GitHub repo Linar-2026/jiuzhaigou-tabletop-ar, choose Add file > Upload files.
3. Upload these 5 files to the ROOT of the repository (not inside a new folder).
4. Commit changes. This replaces index.html; keep old spring/summer/autumn/winter assets if you like, but they are not used by this version.
5. Wait for GitHub Pages deployment. Open https://linar-2026.github.io/jiuzhaigou-tabletop-ar/ in Safari on iPhone 15 Pro Max.
6. Choose Five Flower Lake or Nuorilang Waterfall, rotate/zoom the 3D preview, tap discovery cards, try guided discovery (2 seconds per card), then tap Place on my table.
7. In Apple AR Quick Look, move phone over a well-lit flat table and place the model. Webpage interactions DO NOT continue inside Quick Look. Water magic is a decorative webpage ripple, not 3D water physics. Waterfall in AR is static.
